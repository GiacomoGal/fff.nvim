The help file already in the tree says it was generated by panvimdoc. The action's default input file was not re-checked in the action's repository. A README edit is still avoided: it is the change most likely to make that job write `doc/fff.nvim.txt`, and the job is arranged, by its own comment, around a force-push. The root README and `doc/fff.nvim.txt` are therefore left byte-identical to `fcdf4a9172fba824ca6834731b93b74eba51d1c3`.
